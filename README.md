当前页面不会收集客户资料，也不会跳转支付。部署前请接入中国大陆适用的：

1. 资料提交表单与隐私告知；

3. 客服入口；
4. 服务主体、退款与交付说明。

完成以上配置后，再将申请入口接到 `#upload` 区块。
